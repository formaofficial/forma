# Get started with Forma

## 1. Join and verify

Join [Forma on Discord](https://discord.gg/MqwFSTEdkF), read **rules**, and select **Verify with Discord** in **verify**. Review and approve the Discord permissions to receive the **Member** role. Downloads, key instructions and the community then become visible. The permission to add you to servers is used by Forma only for the Forma server.
The server owner and administrators always see all channels.

## 2. Download

Download the latest Forma installer from the
[official releases](https://github.com/formaofficial/forma/releases/latest).
Run the installer, then open Forma. If Qwen is missing, Forma downloads and verifies the official compatible Qwen Desktop 1.0.3 installer during setup. Keep your existing Qwen data and backups.

## 3. Get your key

Choose **Get a key** in Forma. This opens the
[Forma key website](https://forma-keys.coiledbead32.chatgpt.site/) with your
installation identifier already attached. Continue to Linkvertise and complete
its checkpoint yourself. Stay in the same browser until it returns to Forma's
key page. Copy the complete **FORMA1** key, paste it into Forma and select
**Activate key**. Keep your key private.

Always begin inside Forma: opening the generic website or Linkvertise link alone
does not bind a new key to your installation. Keys last **10 hours**. When yours
expires, repeat these steps on the same installation. Your chats are retained.
Private admin keys do not have the ten-hour limit and bind to the first device that activates them. An internet connection is needed for automatic verification.

## 4. Install and launch Qwen

Open Qwen's card in Forma, choose **Install Qwen and Forma** (or **Install integration** if Qwen is already installed), wait for the completed status,
and choose **Launch**. Forma checks its bundled files before installing them.
It backs up Qwen before applying the integration.

## 5. Choose tool access

- **Read:** inspect files and system information.
- **Confirm:** review actions before they run.
- **Full access:** permit the integrated tools to perform your assigned task.

Choose a workspace folder, then ask Qwen to inspect a small project or show your
system information. Review the tool result before moving to larger tasks.

## 6. Sessions and chat history

Forma's session workflow preserves supported chat history locally. Use your own
authorized accounts and follow Qwen's service rules. Qwen's model availability and
server quotas remain controlled by Qwen; Forma does not provide unlimited tokens.
If a verification challenge appears, complete it yourself. Never share mailbox
passwords or one-time codes in Discord.

## 7. Updates and help

Forma checks for signed releases automatically. When an update is ready, use the
restart/update action in Forma. Official files are published only on the
[formaofficial release page](https://github.com/formaofficial/forma/releases).

For help, open **help** on Discord. For a bug, include your Forma version, what
you clicked and a screenshot with keys, passwords and personal information hidden.

## If something goes wrong

**Key rejected:** copy the entire key, check that it is for this installation,
and get a new one if expired. **Checkpoint error:** open Get a key in Forma again
and use the same browser for the whole trip. **Update download fails:** retry
with a working connection; do not replace verified files with unofficial builds.
